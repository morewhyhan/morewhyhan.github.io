009｜真正获得复利：怎么用对复利公式？

009｜真正获得复利：怎么用对复利公式？

老喻亲述

你好。

我是老喻，欢迎回到《决策算法》课程。

上一讲，我们一起分析了“复利的谣言”，我们赞叹复利的奇迹，但也要承认复利的艰难。

但这并不意味着复利不可能实现。几乎所有厉害的人，都将复利作为成功的关键秘密之一，人世间的许多成功，大多是复利造就的传奇。

怎样真正获得复利？这一讲，我们从复利公式出发，来分析获得复利的方法。

一、复利公式

复利公式，可能是人生当中最重要的公式之一。表达如下：

$$FV=PV\times(1+i)^n$$

其中：

  • FV（Future Value）：是指财富在未来的价值；
  • PV（Present Value）：是指现值，也即指本金；
  • i（interest）：是指单次（单个周期内）的固定利率或固定回报率，即增长比例；
  • n：则是累计的周期，或者说是重复的次数；
  • ×：乘号。

看起来似乎很简单？不。

这个公式背后的意义，要复杂得多，丰富得多。

接下来，让我们拆解复利公式，分析其中的5大要素。

1. FV（未来价值）

表面看，未来价值是一个结果，但也可以是一个目标。

人生的难处在于模糊性和不确定性，所以当下的决策总是条件不足，看不清楚。未来价值提供了一个估值函数，以实现模糊的精确，为人生做指引，给决策做依据。

FV（未来价值）像是一个人的理想，一个公司的愿景。

例如，最早谷歌创立时，市面上有不少搜索引擎，面对投资人的怀疑，创始人说，我们要做的事是AI【原图此处字样需放大复核】。

模糊的大方向，决定了未来的天花板的高度，也能带领我们穿越迷雾，翻山越岭。

2. PV（现值）

PV也可以理解为本金，或者你现在的资源总量。

有人说自己去年的股票赚了80%，完胜绝大多数基金经理。

但是，这个80%的股票，也许只占他资产的不到10%。

所以，现值需要基于整体资产。

但是大多数人或者企业，很难做到这一点。

什么是好生意？是指过去的要素（不是钱）可以积累成更强的、可持续的组织系统能力——这才是真正的雪球，能越滚越大。

苹果厉害的地方是，卖出去的大部分设备，都还在继续为它赚钱。别人买一个手机赚一个钱，苹果种下了一片长久的森林，里面的树木，也就是存量的iPhone和iPad等设备，数以十亿计，而且还在快速蔓延，越长越高。

从这个角度，倒是可以重新理解一下断舍离：如果一株东西，或者公司的某些业务和资源，将来不能创造大于成本的价值，就该扔掉。

3. 增长比例

增长比例是一个动态的数值。正如前面所说，每天增长1%，看似很少，其实很难。

现实中可能是正数，也可能是负数。最终计算出来的FV（未来价值），是一个统计学的结果。

同样，增长比例也与资源的配置有关。例如，一个投资年回报达到了100%，但是只占用了10%的资金，在整个复利公式里增长比例就变成了10%，而非100%。

4. n是重复的次数

1964到2021年间，伯克希尔实现了3.64万倍的市值增长。这期间，伯克希尔的年化回报率约为20%。

你看，要想实现财富的复利奇迹，需要活得够久，重复得够多。

5. 乘号

全世界所有人的头发的数量相乘，结果是多少？是零。只要有一个人没头发。

这是复利公式的残忍之处。

人生是一连串的乘法。乘法将我们的时间和资源连接起来，这里面有并联，还有串联。但最后都可以用复利公式来计算。

每一个乘号，就是一次决策。单次决策发生之时，需要是无记忆的，也就是相对其他决策独立，甚至是对上一个乘号的增加。但是每次决策必须基于当下的整体资产。

二、怎样让复利公式为你服务

公式很重要，但是公式是中性的，就像我们无法单纯用牛顿的公式建一座大桥。

怎么让复利公式真正为你服务呢？我总结为以下5点：

第一，你要拥有自己的“雪球”

你一定听过巴菲特的名言：“人生就像滚雪球，重要的是找到很湿的雪和很长的坡。”

要想实现复利，你首先需要有自己的、值得滚的“雪球”。

换而言之，你必须有个有价值的东西。

就创造财富而言，你的“雪球”可以是本金，优秀企业的股权，能带来租金的物业，还可以是你的某个知识产权，还包括个人IP等。

不管是公司，还是个人，有没有一个资产平台，来沉淀自己的资源，并且基于这个平台来滚雪球，是能够实现复利效应的关键所在。

日拱一卒无有尽，功不唐捐终入海。这个“海”，就是资源平台。

否则“日拱一卒”后面，跟着是猴子掰苞米。

你需要有一个资源平台——可能是你的名声，你的一个视频号，你的公司，你创立的品牌——依靠这个平台，把你的所有努力和付出都叠加起来。

当然，前提是你的专业和独特价值。

第二，在惊涛骇浪中穿行

种下复利的种子，也许较如园丁。但是实现复利的过程，犹如在大海中航行。

巴菲特买亚迪的股票，起初暴涨，随后回跌，接着十多年无法突破。一般人早要掉了。又有多少人能够像巴菲特一样，经历大风大浪的起伏，最终收获三四十倍的回报？

传统的“复利思维”，鼓吹持续每天进步百分之0.05，只是追求一种所谓确定性的幻觉，稍微遇到一点儿风雨就被打散了。

更大的挑战是，别让你的船被一个浪头打翻了。

厉害的人还要能够在没有任何激励、没有任何“进步迹象”的情况下，依然每天打满鸡血。为什么能做到这一点呢？

秘密在于：他们既有心中的北极星，又敢于走入漫无边际的汪洋大海。

第三，专注聪明地重复

世界是熵增的，滑滑梯的乐趣，只有小孩子才有。上一讲我们说过，复利的滚雪球，其实是像西西弗斯一样，是往山坡上推。

所以，我说向上的电梯，你要勤奋。天下没有免费的午餐，复利追求的是超额的回报，你也需要有对应的超额付出。

找到值得大规模重复的事情之后，我们更需要长期专注，对那些不是决定性的机会和任务说不。

OpenAI的CEO说：“如果你在聪明和勤奋中占了一项，就能超过90%的人。但想超过99%的人，必须聪明+勤奋。因为你的竞争对手往往是这样的人。”

他有一个精彩的洞见：“勤奋有复利效果，往往能带来一个又一个惊喜，肯定产生巨大的生活乐趣。”

这个前提，当然是你在一个对的地方，和对的人，做一件对的事情。

一位著名作家对我说，每天不管有没有灵感，她都在桌前写四个小时。

我自己很缺乏自律。于是就选择和得到合作，这样就不得不赶稿子，而是在得到的品控之下不断打磨。

第四，一边“滚雪球”，一边“补血”

滚雪球，要找到很湿的雪和很长的坡。但很多人忽略的是，雪球越滚越大，只是一个理想化的比喻，在现实中，雪球有时不会越滚越大，还经常会“掉血”。

高手会怎么做呢？他们会一边“滚雪球”，一边“补血”。

职业投资人和业余投资者最大的区别之一，在于职业选手有源源不断的弹药。

巴菲特投资，不光靠自己手里的资金，他还可以调用旗下保险公司的浮存金；巴菲特也可以低成本发债，不差钱的他曾经在日本借了18亿美元，套利的同时，又补充了弹药。

除此之外，巴菲特还强调所投公司有很好的自由现金流，他有一个极小的总部，只在为旗下公司的经理们把剩余的资源源源不断地投上来。

只有如此，无限游戏才可以持续下去，英雄一直留在场上，等到大数定律发挥作用，复利最终实现。

这是“长期主义”背后的道理。

换句话说，他们一边滚雪球，一边不断在前面的雪道上撒雪。

对于我们普通人来说，“补血”还意味着终身学习，和永无止境的自我完善。

第五，活得久，动得早

复利公式是由很多个乘号串起来的，本身非常脆弱，一不留神就掉链子，或者归零。

所以，首先要活下来，然后是活好。

并且，越早开始滚雪球越好。如果不够早，那就从今天开始。

如何既不出局，又不旁观？一个人如果想要构建自己的复利系统，需要具备健壮性，以实现稳态。

我们在前面学习的EKB算法，通过胜率、赔率、期望值、凯利公式、贝叶斯定理，构建了一个四维的决策系统，就是为了实现一种防范风险、持续增长的人生复利。

总结

复利公式是一个关于财富的公式，但它也给出了一个关于人生的简洁而美妙的隐喻框架。

我们未必在现实中总是进行计算，但是这个公式能帮助我们理解人生中最本质的某些问题。其简洁和深刻，胜过许多冗长的人生道理。

从本质上来说，复利公式，是基于时间轴，对一个人或企业的“资产、认知、劳作”的持续复制。

这个复制是动态的，环境充满了不确定性，热力学第二定律处处心想恶意想要阻止你滚雪球。

因此，你需要稳固的内核、坚定的信念，才能穿越不确定性。

自我的认识，可能是复利公式里最重要的隐藏要素。复利公式里的一个乘号，其实就是一个人的自我进化过程。

传奇投资人、大卫·史文森，在一张手写稿中，强调了一个重要的“教训”：“真正的秘诀是什么？人，人，人。”

他说：“真正的秘诀在于，与绝对高质量的人建立关系。”

当然，更要让自己不断成为一个更加高质量的人。

这是获得复利的前提，也是让复利可以持续积累的关键。

祝愿你早日开始人生复利的积累。

我是老喻，我们下一讲再见。

划重点

让复利公式真正发挥作用的五个要点：

  1. 拥有自己的“雪球”；
  2. 在惊涛骇浪中穿行；
  3. 专注聪明地重复；
  4. 一边“滚雪球”，一边“补血”；
  5. 活得久，动得早。

左星星

每每讲到复利效应，人们很容易把“财富自由”联想到一起。我们可以结合复利效应，把“财富自由”用公式来表示：

本金×（1+收益率）^时间 = 财富自由

这个公式指的是只要非劳动收入大于消费欲望，就达到了财富自由。

从这个公式出发，抓住其中的几个变量，我们就能明白财富自由的关键：

一是尽早存到足够的本金。获得财富自由的第一要素是，越早积累本金的能力。赚钱得靠本金，而不是靠复利。你都没有本金，哪来的钱生钱呢？

二是努力做到稳健高收益。找到高收益的投资不难，识别背后的风险很难。你看中的是别人的利息，别人看中的是你的本金。

三是让时间证明它的力量。要有把压岁钱存成养老金的足够耐心，还要保持健康的饮食、坚持运动，拥有良好的心态和社交。

四是降低自身的贪心与欲望。欲望是无法填平的，只能降低。

做到以上这几点，你才能离财富自由更近一些。

这节课对FV的理解，不只是从数学上的理解，还是从目标、愿景的理解，多了一层高度，而且考虑到决策的模糊性和不确定性。我对巴菲特和复利公式研究多年，老师的演绎，在思想层上又上了一个新的台阶。除了5个要素、两个计算符号的多元演绎，还考虑到现实这个公式的现实难度：不确定性和连续性。鼓吹持续每天进步1%，只是追求一种所谓确定性的幻觉，稍微遇到一点儿风雨就被打散了。就像每天练琴、练字一样，绝大部分都很难坚持一样，很多事情，要考虑的成功与否，先考虑的是人性，而不是理论上的公式。

王惠玲

今天最受启发的点：

  1. 拥有自己的雪球。老师说：“真正厉害的人，还能够在没有任何激励、没有任何进步迹象的情况下，依然每天打满鸡血，他们既有心中的北极星，又敢走入漫无边际的汪洋大海。”勉励着我，我处于构建“雪球”阶段，想拥有一门专业和独特价值技能，现在正处于没有反馈、没进步迹象，但没有放弃，每天乐津津地逢人分享职业生涯知识，有客户就做，有客户复习，我同学对练，深耕得到APP提知识、增见闻、做反思、写留言、用起来。
  2. 在惊涛骇浪中穿行。我认定咨询是适合我，深知需要时间积累和体感才找出属于我小众市场，一边探索一边沉淀。
  3. 专注而聪明地重复。还没有找出适合我的小众需求，每天保持2小时输入、1小时输出，利用一切机会分享，探索小红书文字输出。
  4. 一边“滚雪球”，一边“补血”，我是终身学习者，学习也是投资方式，投资要考虑成本、收益和现金流，不会盲目报读课程，而是重温已购课程，实在有必须再买新课程。
  5. 活得久，动得早。我还有8年退休，成为知识服务者为退休做打算，提前8年进场该属于早进场。
