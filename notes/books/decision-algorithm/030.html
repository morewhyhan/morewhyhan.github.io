030｜关键时刻：怎样把握最佳出手时机？

你好

我是老喻，欢迎来到《决策算法》课。

我们在课程一开头就讲过，决策基础是胜率和赔率。但是很多决策场景下，胜率并非固定不变，而是会随着局势变化，有时高一些，有时低一些。于是，时机就成为成败的关键。

这一讲，我们就来讨论这个重要的决策难题：怎样把握最佳的出手时机？

一、三个人的决斗

先来做一道思考题：

A、B、C 三生子连环决斗，规则如下：

  1. 抽签决定开枪顺序；
  2. 有开枪权者可以自行选择射杀对象；
  3. 每次只能开一枪；
  4. 直至剩下一个人。

已知 A 和 B 百发百中，都是神枪手，而 C 的命中率是50%。

请问谁活下来的概率最大？是多少？

解答如下：

抽签顺序可能有六种可能性——ABC、ACB、BAC、BCA、CAB、CBA。

前四种可能性，A 和 B 都会选择先开枪干掉对方——毕竟要先消灭厉害的对手，然后轮到 C 开枪，50%概率干掉一个人。

问题的重点是，后两种可能性，C 先开枪时，他该怎么办？

他最明智的办法是对天开一枪。

也就是说，即使他获得了优先开枪的权力，也应该放弃掉。

我们先设想一下，由枪法最差的 C 开枪，他选择打 A 或者 B，命中率是50%：

  • 假如他打中了，接下来活着的那个神枪手会100%干掉他；
  • 假如他没打中，那还好，那是一个神枪手干掉另一个神枪手。

与其如此，C 的最佳策略是，对天开一枪，100%没打中；然后留着 A、B 彼此开枪，无论如何死一个人，最后再由 C 开枪，50%概率得手。

结果，生存概率最大的，居然是枪法最差的 C。

所以，在特定条件下，弱者也能生存。关键在于，你能够忍耐，等候最佳的开枪时机。

二、线列步兵战术

再看和出手时机有关的案例。

18至19世纪的欧洲，有一种战术在今天看来很奇怪。如果你看过《战争与和平》等描述当时战争场面的电影，可能看到过这样的场面：士兵排排站，列成方阵，然后面对面整齐地射击。

这一看似荒诞的画面让人不禁质疑：为什么士兵们要排成整齐的队列，像是等待着无情的子弹洗礼？这些勇士难道不懂得躲避，或者寻找掩体？

但这种被后世戏称为“排队枪毙”的战术，竟然主宰了欧洲战场近两百年，甚至帮助欧洲列强征服了世界。

是什么让这种看似自杀性的阵型，成为了那个时代的“最优解”？

线列步兵战术的一部分灵感来自古罗马军团的编队和组织。罗马军团以其严格的队列和战斗阵型著称，而这些元素在后来的线列步兵战术中得到了延续和发展。

线列步兵战术起源于欧洲火枪和刺刀的普及时期。当时，士兵们使用的是滑膛枪，这种武器装填缓慢且精度低。普通士兵一分钟只能发射2—3次，经验丰富的士兵最多可达4—6次，但在实际战斗中，因为种种因素，这个速率通常更低。此外，当时的火药产生大量烟雾，严重影响了战场视野和射击精度。

线列步兵战术的核心是将士兵排列成横队，通过集体射击来最大化火力覆盖。这种方法不仅提高了命中率，还使得每个士兵的火力得以集中使用，避免了单兵射击的低效。这种集体射击的方式，在当时的技术条件下，是利用火器的最佳选择。

此外，线列步兵战术还有“简化指挥与控制、有效使用刺刀、对敌人产生心理威慑”等优势。

在1815年的滑铁卢战役中，威灵顿公爵展现了线列步兵战术的精妙之处。他命令手下步兵组成空心方阵，将炮兵安置在火枪兵之间。这一战术布局不仅增强了火力密度，还有效保护了炮兵免受敌军骑兵的袭击。

英军被指示只有在敌人接近到二十米内时才开火，这一策略旨在确保每一发子弹都能发挥最大效用。

与此同时，法国的内伊元帅率领骑兵冲锋而来。在距离百米处，法国骑兵首次遭遇英军炮攻击。随着距离缩短至二十米，英军的火枪齐射开始了。这一近距离的齐射给法军骑兵带来巨大伤亡，因为即便是精度较差的火药枪，在如此近的距离上也能造成致命打击。第一轮齐射几乎瓦解了法军的冲锋，而第二轮火力则彻底击溃了残余的骑兵。

这种近距离的人力集中展示了线列步兵战术的优势：尽管这种战术看似简单甚至愚蠢，但在那个没有现代机枪的时代，它却能在近距离作战中造成巨大的杀伤。滑铁卢战役不仅是威灵顿公爵的胜利，更是线列步兵战术的经典案例，展示了其在战场上的强大威慑力。

三、魁北克战役：等待最佳时机

体现线列步兵战术精髓的另一场战役，发生于1759年，史称“魁北克战役”。

整场战役只打了30分钟，却改变了历史。

法军守将蒙卡尔姆率兵对阵英军。他平常小心而有条理，而这次却没有耐心等待最佳时机反击，当敌人还在百米开外的时候就射击，对英军没有构成太大的损伤。

与之相反，英军采用了一种非常谨慎而有效的策略。当法军率先发起攻击时，英军并未立刻回应，而是保持队形，静待敌军进一步逼近。

一直到两军足够近（有资料说是30多米距离），英军第一轮齐射一下子就打乱了法军阵脚，紧接着，英军继续向前推进，距离更近时打了第二轮齐射，法军彻底崩溃。

法军惨败，再次说明一个朴素的道理：

没有胜算时贸然出击，只是在浪费子弹。

四、集中发力，遵守纪律，等待时机，果断出手

接下来，让我们撤出历史上的战场，回到现实的决策场景。

线列步兵战术，某种程度也反映出我们在做决策时常面临的真实困境：有时候，手头的武器就是很烂，准头也不够，射程也不够，没有什么高精尖的武器，此时要如何取胜？

制胜策略包括四个关键词：集中发力，遵守纪律，等待时机，果断出手。

我们用一场抗洪抢险来说明这四个关键词如何发挥作用。

1993年，美国密西西比河流域遭遇特大洪水，洪水持续数月，对中西部多个州造成严重破坏。大量城镇、农田、基础设施面临洪水威胁。为抵御洪水，地方政府、军队、志愿者和社区居民纷纷投入紧急抢险。

在洪水暴发之初，许多社区居民和志愿者虽然热心，但缺乏经验，往往采用自发、零散的方式往河岸边丢沙袋。结果是，大多数沙袋没有形成连续的堤坝结构，轻易被水冲走，志愿者辛苦填装和搬运的沙袋被浪费，宝贵时间也被耽误。

后来，美国陆军工兵部队抵达现场，防洪行动得到了专业指导和组织管理。

首先，志愿者排成几队，有人专门填沙袋，有人专门传递，最后有人专门在指定位置按特定方式堆叠沙袋。

其次，堆叠沙袋讲究也能很多，比如要交错叠放，多层叠加、压实，不能只是简单地往水里丢。这样才能形成一道能持续、稳固的临时堤坝。

此外，还必须抢在时间窗口内出手，必须要在下一次洪峰尚未全面冲击，或在关键决口点出现前，快速完成一定长度和高度的沙袋堤坝，这样才不会被洪水冲毁。

这个案例也让我们再次确定一个基本常识：这世界上不存在以弱胜强的传奇，劣等资源也不可能战胜优等资源。

劣等资源要创造奇迹，唯一的办法是，聚焦单点，制造局部优势。统一号令，严格遵守纪律，耐心等待，以及精准的时机把握，和果断出手。

然而，必须要承认的是，在一些更加区险的决策场景下，要能做到非常困难，于是，就需要一个关键要素加持，那就是“勇气”。

五、《勇敢的心》：Hold

我第一次看电影《勇敢的心》时，最受触动的一个场景是，英国骑兵以压倒性优势，冲向威廉·华莱士（梅尔·吉布森）率领的苏格兰人。看起来手持破铜烂铁的民兵，该如何应对全副武装的骑兵？

当敌军战马以越来越快的速度冲到阵前，当骑士们举起了长矛，威廉·华莱士一直在大喊“Hold……Hold……Hold……Hold”，他一共喊了四声，直至敌军来到眼前，才命令战友们举起了早已准备好的削尖的长木棍，将来不及停下来的敌人骑兵挑于马下。

这一场景，从战术的角度看，非常像“线列步兵战术”：一直到敌人来到最后的底线，才齐齐举起武器，一起发射，给出对方致命一击。

在那一刻，有多少人能够承受压力呢？连最信任威廉·华莱士的伙伴，在最后关头也犹豫不决地望着他。

即使你用对了“线列步兵战术”，也要冒着生命的危险。就像“魁北克战役”中阵亡的英军将领沃尔夫少将。事实上，在“魁北克战役”中，英军的伤亡也不小，英军将领沃尔夫少将也挨了三枪被打死。

更何况，“线列步兵战术”早已成为历史名词，现代军事行动更强调火力、机动性、隐蔽性和灵活的指挥控制。

然而，不管怎样，在现实世界里，如果大敌当前，你需要的不仅是武器，还有勇气和智慧。

而最大的智慧，往往与机遇有关。如同前面的智力题，为了等待最佳时机，牛仔会放弃优先射击的机会。

六、钓鱼与等待

决策有趣的地方是，假如你理解了其中的一些基本原理，你不必去读一堆书，也不用去进商学院，只要运用非常简单的决策框架，就有可能让自己有脱胎换骨的飞跃。

这一讲的基本智慧就是：当你遇到重大决策问题时，别马上做出决定，而是耐心等上一阵子。

我的一位好朋友，分享了他特别敬佩的一位前辈高手的故事。有一次，那位前辈的企业遭遇了大规模的舆论攻击，竞争对手造谣说他们出现了致命危机，接近破产，人也出问题了。一时间，乌云密布，所有人都在传这件事，朋友们也替他着急，公司同事们也异常愤怒，建议立即辟谣，对大众解释。

这时，这位前辈高手做了一个决定：24小时之内，不采取任何行动。

这是一个身边人难以理解的艰难决定，因为不解释、不反击，意味着谣言继续满天飞，甚至会发酵。但是，这位高手的观点是：你不知道对手到底是谁，你也不知道他的目的是何，保留然后反击，只会乱了阵脚，也不会真正遏制对方的行为。等上1天，让子弹再飞一会儿，找到幕后黑手，摸清对方的意图，再集中火力，针对性地反击。要么不还手，要打就一举拿下。

果然，他们最终度过难关，赢得了胜利。

也许，我们的生活中并没有那么多你死我活的时刻，可你我总会面对一些压力，不得不处理一些麻烦。有些事情可能会让你火冒三丈。

这时，记得如电影《勇敢的心》一般，面对千军万马，对自己说：

Hold……Hold……Hold……Hold……（挺住……挺住……挺住……）

在关键时刻才出手，但也要守住最后的底线。

Hold，挺住，不仅是一种勇气，更是一种智慧。

七、钓鱼时的信号

在交易市场中，很多人也会犯“过早出手”的错误。钓鱼的时候，鱼线上会有鱼漂。鱼漂的本质就是一个信号系统，我们通过鱼漂观察水里的鱼是否在咬钩，鱼漂动了，适当的时候你就要立刻提竿；鱼漂不动，说明没有鱼在吃鱼饵，此时你要做的就是观察鱼漂的变化，在鱼饵不动之前你拿着鱼竿，耐心等待。

水里面有很多游来游去的鱼，这些鱼其实和钓鱼者没有关系，我们不用着心神不定地盯着这些鱼。临渊羡鱼，不如退而结网。只有咬住了你的鱼钩，鱼漂动了，这条鱼才和你有关系，这就是我们要的信号。

做市场交易的道理也是如此，作为交易者我们需要耐心等待鱼漂所发出的信号，如果鱼漂没有浮动，那市场的走势再热闹，也和你没有关系，此时你能做的唯一耐心等待，而不是乱作为，如果你非要乱作为的话，那就是自己作死。

关于等待的重要性，《孙子兵法》的第四篇军形篇中，写道了这样一句话：

昔之善战者，先为不可胜，以待敌之可胜。

这句话的大致意思是，古代善于作战的人，先让自己不可被战胜，然后耐心等待可以战胜敌人的时机。这句话的精髓就在于一个“待”字，而事实上呢，很多人都患有行动焦虑症，于是就陷入了自己作死的境地。

以上就是这一讲的全部内容。

我是老喻，我们下一讲再见。

划重点

  1. 在特定条件下，弱者也能取胜，关键在于，你能够忍耐，等候最佳出手时机。
  2. 劣等资源要创造奇迹，唯一的办法是，聚焦单点，制造局部优势，以及统一号令，严格遵守纪律，精准把握时机和果断出手。
  3. 一个决策的基本智慧：当你遇到重大决策问题时，别马上做出决定，而是耐心等上一阵子。

在知乎上有这样一个问题，交易中最重要的环节是什么呢？答案千奇百怪，有说是不要频繁交易的、有说是设置止损的、也有说是浮盈加仓的。嗯，这些答案都很重要，但不是最重要。在我看来最重要的环节就是耐心等待，等待属于你的交易信号的出现，然后果断出手，狠狠地咬上一口。

其实做市场交易和钓鱼是类似的。不知道你有没有想过，钓鱼的时候，鱼线上会有鱼漂。为什么会有鱼漂？鱼漂的本质就是一个信号系统，我们通过鱼漂观察水里的鱼是否在咬钩，鱼漂动了，适当的时候你就要立刻提竿。鱼漂不动，说明没有鱼在吃鱼饵，此时你要做的就是观察鱼漂的变化，在鱼饵不动之前你拿着鱼竿，耐心等待。

水里面有很多游来游去的鱼，这些鱼其实和钓鱼者没有关系，我们不用着心神不定地盯着这些鱼。临渊羡鱼，不如退而结网。只有咬住了你的鱼钩，鱼漂动了，这条鱼才和你有关系，这就是我们要的信号。做市场交易的道理也是如此，作为交易者我们需要耐心等待鱼漂所发出的信号，如果鱼漂没有浮动，那市场的走势再热闹，也和你没有关系，此时你能做的唯一耐心等待，而不是乱作为，如果你非要乱作为的话，那就是自己作死。
